# Безопасность

Эти инварианты не меняются без явного указания в задаче.

- **Пароли:** только argon2id. Сравнение — через `argon2.verify`, никогда через строки.
- **Токены** (сессии и письма): случайные 32 байта из `crypto.randomBytes`. В БД хранится только SHA-256 хеш.
- **Кука `sid`:** `httpOnly`, `sameSite: 'lax'`, `secure` в продакшне, `path: '/'`.
- **Одинаковые ответы.** Неверный email и неверный пароль дают одинаковый ответ `INVALID_CREDENTIALS` за сопоставимое время. `password/forgot` всегда отвечает 204.
- **Проверка `Origin`** для изменяющих запросов не отключается, в том числе в тестах: тесты передают правильный `Origin`.
- **Редиректы** принимают только относительные пути, начинающиеся с `/` (но не с `//`).
- **Логи.** В логи не попадают пароли, токены, куки и `passwordHash`.
- **Стек ошибки** никогда не уходит в ответ.
- **Лимиты запросов** на `/auth/*`, сдачи и обращения не снимаются.
- **Сырые SQL-запросы** — только параметризованный `$queryRaw` через шаблонную строку. `$queryRawUnsafe` запрещён.
