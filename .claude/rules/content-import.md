# Импорт контента

- **Формат.** Источник истины — `docs/CONTENT-FORMAT-SHARED.md`. Если формат меняется, сначала меняется этот документ (и его копия в `edu-content`), потом код.
- **Порядок работы.** Сначала валидируется весь пакет, потом что-то пишется. При любой ошибке ничего не записывается, а в сообщении указывается путь к файлу.
- **Транзакция на курс.** Частично импортированных курсов не бывает.
- **Импорт ничего не удаляет.** Расхождения попадают только в отчёт.
- **Опубликованный контент.** Перевод со статусом `PUBLISHED` без `--force` не перезаписывается.
- **Картинки.** Ссылки в Markdown переписываются только для файлов, которые реально скопированы из `assets/`.
- **Сухой прогон.** `--dry-run` не пишет ни в БД, ни в `MEDIA_DIR`.
