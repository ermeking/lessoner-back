## 1. Продукт в двух словах

Доступная текстовая платформа для изучения программирования в формате учебника. Путь ведёт от нуля до middle и дальше, с практикой и автопроверкой кода. Базовые курсы бесплатные, остальные — 100 сом за курс, доступ навсегда. Сайт работает на трёх языках: кыргызском, русском и английском. Первое направление — Frontend на JavaScript.

## 2. Сущности

| Термин | В коде | Что это |
|---|---|---|
| Направление | `Track` | Frontend, Backend и т. д. Содержит курсы по уровням |
| Курс | `Course` | Единица покупки. Уровень `JUNIOR` / `MIDDLE` / `SENIOR`, доступ `FREE` / `PAID`, цена в сомах |
| Модуль | `Module` | Раздел курса. Задел под «тест на пропуск» (v2) |
| Урок | `Lesson` | Текст учебника в Markdown и задания. `isPreview` открывает урок платного курса без покупки |
| Задание | `Exercise` | Условие, стартовый код, тесты, три подсказки, эталонное решение |
| Перевод | `*Translation` | Тексты сущности на одном языке, со своим статусом |
| Сдача | `Submission` | Попытка решить задание: код и результат тестов. Сохраняются все попытки |
| Прогресс | `LessonProgress` | Статус урока у ученика: `IN_PROGRESS` / `COMPLETED` |
| Доступ | `AccessGrant` | Право на платный курс: покупка, ручная выдача или промокод. Бессрочное |
| Обращение | `ProblemReport` | Сообщение ученика «урок непонятен / ошибка в задании» |

Один курс может входить в несколько направлений (`TrackCourse`).

## 3. Языки и переводы

Поддерживаемые языки: `ru`, `ky`, `en`. Оригинал контента пишется на `ru`.

Статусы перевода: `DRAFT` → `REVIEW` → `PUBLISHED`. Снять с публикации можно переходом `PUBLISHED` → `DRAFT`. Другие переходы запрещены.

**Откат на русский.** Публично показываются только переводы в статусе `PUBLISHED`. Если на запрошенном языке опубликованного перевода нет, отдаётся опубликованный русский с флагом `isFallback: true`, а сайт показывает плашку «Перевод готовится». Если нет опубликованного даже русского перевода, сущность публично не видна.

Интерфейс сайта (кнопки, меню) переводится отдельно от контента и доступен на всех трёх языках с первого дня.

## 5. Доступ и прогресс

В API эти правила живут только в `AccessService` и полностью покрыты юнит-тестами. Фронтенд их не вычисляет, а отображает состояния, которые пришли от API.

### 5.1. Видимость

Направление и курс видны, только если у них `isPublished = true`. Для текстов действуют правила перевода из раздела 3.

### 5.2. Чтение урока

| Курс / урок | Гость | Вошедший без доступа | Вошедший с доступом |
|---|---|---|---|
| Бесплатный курс, любой урок | читает | читает | читает |
| Платный курс, превью-урок | читает | читает | читает |
| Платный курс, обычный урок | нет | нет | читает |

### 5.3. Практика: «читать свободно, сдавать по порядку»

1. **Запуск тестов.** Запускать тесты может любой, кто может читать урок, включая гостя. Тесты выполняются в браузере.
2. **Сохранение.** Сдачи сохраняются только у вошедшего пользователя. Сохраняются и успешные, и неуспешные: неуспешные нужны для статистики.
3. **Порядок.** Сдача засчитывается, если урок доступен по порядку: он первый в курсе или предыдущий урок курса завершён. Порядок уроков: сначала `position` модуля, затем `position` урока.
4. **Завершение урока.** Урок завершён, когда пройдены все его задания. Урок без заданий завершается кнопкой «Урок прочитан» с той же проверкой порядка.
5. **Эталон.** Эталонное решение выдаётся, если у пользователя есть успешная сдача задания или он открыл все его подсказки.
6. **Доверие.** Результату проверки из браузера доверяем: защита от обмана не окупается при цене 100 сом.

### 5.4. Состояние урока для вошедшего пользователя

| Состояние | Значение |
|---|---|
| `COMPLETED` | Урок завершён |
| `AVAILABLE` | Можно читать и сдавать |
| `LOCKED` | Можно читать, сдавать нельзя: не завершён предыдущий урок |
| `NO_ACCESS` | Урок платного курса без доступа |

## 6. Коды ошибок

Каждая ошибка API приходит в формате `{ "code": "...", "message": "...", "details"?: [...] }`. `message` нужен только для логов и отладки: ученик видит перевод кода, который делает фронтенд. Новый код добавляется сначала в эту таблицу, затем в API и в переводы фронтенда.

| Код | HTTP | Когда |
|---|---|---|
| `VALIDATION_ERROR` | 400 | Неверные входные данные; `details: [{ field, rule }]` |
| `UNAUTHORIZED` | 401 | Нужен вход |
| `INVALID_CREDENTIALS` | 401 | Неверный email или пароль (ответ одинаковый для обоих случаев) |
| `FORBIDDEN` | 403 | Недостаточно прав для роли |
| `ORIGIN_FORBIDDEN` | 403 | Изменяющий запрос с чужого `Origin` |
| `USER_BLOCKED` | 403 | Пользователь заблокирован |
| `COURSE_NOT_PURCHASED` | 403 | Урок платного курса без доступа |
| `LESSON_LOCKED` | 403 | Сдача не по порядку |
| `SOLUTION_LOCKED` | 403 | Эталон пока недоступен |
| `NOT_FOUND` | 404 | Сущность не найдена или не опубликована |
| `EMAIL_TAKEN` | 409 | Email уже зарегистрирован |
| `HAS_SUBMISSIONS` | 409 | Нельзя удалить урок или задание, по которым есть сдачи |
| `INVALID_STATUS_TRANSITION` | 409 | Недопустимый переход статуса перевода |
| `TOKEN_INVALID` | 400 | Токен письма истёк, уже использован или не существует |
| `PAYLOAD_TOO_LARGE` | 413 | Код сдачи больше 50 КБ |
| `RATE_LIMITED` | 429 | Слишком много запросов |
| `INTERNAL_ERROR` | 500 | Непредвиденная ошибка |

## 7. Версии продукта

| Версия | Содержание |
|---|---|
| v1 — бесплатный запуск | Аккаунты, бесплатные курсы, чтение, задания с автопроверкой, прогресс, подсказки, обращения, админка контента и переводов, импорт контента |
| v2 — монетизация | Оплата, платные курсы, квизы, тест на уровень, тесты на пропуск модуля, кыргызские версии бесплатных курсов |
| v3 — опыт | Курс по Git, финальные проекты через GitHub, раздел подготовки к собеседованию |
| Позже | AI-помощник (Akylai), взаимная проверка проектов, новые направления, сертификаты, промокоды |

Функции будущих версий не реализуются, пока задача явно этого не требует.
